# ShoeFlow ERP 系统与登录

## 系统定位

ShoeFlow ERP 用于鞋类 SKU 档案、扫码入库、实时库存、销售出库、退货冲销、库存校正和经营统计。ERP 数据库是库存、成本、销售额和利润的唯一真实数据源。AI 经营助手只能通过后端提供的业务工具读取或处理数据，不能绕过接口直接修改数据库。

## 登录与认证

打开网页端或手机端后，使用 ShoeFlow 系统账号和密码登录。登录成功后，系统保存访问令牌并在后续接口请求中自动携带。数据库账号密码、DeepSeek API Key 和 JWT 密钥都不是前端登录密码，不能填写到登录页面。

出现“登录已失效”或 HTTP 401 时，返回登录页重新登录。若正确账号仍无法登录，应先确认 FastAPI 后端已经启动、手机与电脑位于同一局域网，并确认手机端的 API 地址指向电脑当前局域网 IP。

## 手机连接后端

电脑浏览器可以使用 `http://127.0.0.1:8000` 访问本机后端。Android 真机不能用 `127.0.0.1` 访问电脑，因为手机上的该地址代表手机自己；手机端应使用电脑的局域网 IPv4 地址，例如 `http://192.168.1.149:8000/api/v1`。

电脑启动后端时使用 `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`。手机和电脑需要处于同一局域网，Windows 防火墙也要允许 8000 端口的局域网访问。USB 数据线只用于安装和调试应用，不能替代局域网网络连接。

## 功能入口

系统主要功能包括：AI 经营助手、扫码入库、销售出库、库存查询、商品档案、退货冲销和经营数据。库存查询页面适合查看完整库存列表；AI 经营助手适合用自然语言查询某个商品、生成销售预览或询问系统操作方法。
